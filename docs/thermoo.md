# Thermoo

---

</div>

Thermoo is the shared foundation that [Frostiful](./frostiful.md) and [Scorchful](./scorchful.md) are both built on. It started as a way to avoid duplicating temperature logic across two mods, and has grown into a mature library that provides APIs for both mods and datapacks to build upon.

If you're a developer looking to use Thermoo, the developer wiki is the best place to start: [https://thermoo.thedeathlycow.com](https://thermoo.thedeathlycow.com)
