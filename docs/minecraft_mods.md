# Minecraft Mods

This is an overview of my mods for the game *Minecraft: Java Edition* by Mojang Studios. All of these mods are primarily written in the Java programming language, however I have also worked with Kotlin to a small degree as well. My Minecraft mods are primarily published onto the platforms [CurseForge](https://www.curseforge.com/) and [Modrinth](https://modrinth.com/), which are more player-centered. I also always publish my source code on my [GitHub account](https://github.com/TheDeathlyCow/).

---

## Frostiful
**Frostiful** is a mod focused on cold-weather survival and magic that I have developed and maintained since February 2022. It was inspired by games such as *Subnautica*, *Subnautica: Below Zero*, and *The Long Dark*, as well as the *Skyrim* mod *Frostfall*. My primary goal was to create a temperature system that is Immersive, Intuitive, and Interesting. I did not want to just create a another tedious layer of difficulty for the player to manage. Along the way I have had to take on feedback, handle bug reports, review pull requests, provide community support and documentation, ensure inter-mod compatibility, and continuously iterate on new features to make them as fun as possible.

## Scorchful
**Scorchful** is a mod focused on warm-weather survival and mind control. It is a companion mod to [Frostiful](#frostiful) but came with its own set of unique challenges.
